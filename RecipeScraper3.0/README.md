# 水藍魔力配方計算器

以瀏覽器開啟的本機小工具，直接讀取 `recipe/` 與 `material/` 內的 JSON。

## 直接開啟

雙擊專案根目錄的 `recipe-calculator.html`，即可在瀏覽器中離線使用，不需要開啟 PowerShell 或安裝其他程式。

單檔頁面會內嵌產生當下的配方與素材資料。若更新 JSON 資料後要更新離線頁面，請在專案根目錄執行一次：

```powershell
node build-standalone.mjs
```

這只在重新產生頁面時需要；日常開啟和使用不需要 PowerShell。

開發時仍可執行 `python -m http.server 8000`，再開啟 <http://localhost:8000>。`index.html` 是開發入口，`recipe-calculator.html` 是可直接雙擊的離線單檔版。

## 使用方式

1. 在「配方清單」選擇配方類別、道具與目標製作數量，再加入清單；可加入多種配方，並可切換依加入順序或道具種類分組檢視。
2. 計算器會彙總共用素材。若配方每批產出多個道具，輸入目標數量後會向上取整為完整批次。
3. 在「素材單價」輸入每個素材的單件成本。留白表示尚未設定；成本保存在目前瀏覽器，並可匯出 JSON 備份。

價格與配方清單只儲存在目前瀏覽器的網站儲存空間，不會改寫素材來源 JSON，也不會自動同步到其他瀏覽器或裝置。不同瀏覽器可能會分別儲存檔案網址下的設定；請使用單價備份功能匯出設定。
